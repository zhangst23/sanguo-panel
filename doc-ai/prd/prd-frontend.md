# WordPress极速云托管面板 · 前端策划方案  
**主题**：简洁轻量 · 无感性能融合 · 极速管理体验  

---

## 一、设计理念

**1. 不做“技术参数堆砌”，做“业务场景引导”**  
- 用户不是来学习 OpenLiteSpeed、LSAPI、Redis 的，是来**管理网站并让它变快**的。  
- 所有底层优化能力都封装在业务操作背后，用户无需感知技术名词即可获得速度提升。  

**2. 极简信息层级，三步触达核心操作**  
- 90% 的日常操作（建站、清理缓存、看监控）在 2 次点击内完成。  
- 高频功能放置在 Dashboard 快捷卡片中。  

**3. 实时、可视、可感知**  
- 性能优化效果通过**速度评分、TTFB 数值、缓存命中率**等可视化指标呈现，让用户“看到”快。  
- 后台状态变化通过 WebSocket 实时推送，图表动态刷新。  

**4. 一致性体验**  
- 基于 Arco Design Vue 基础组件，统一色彩、圆角、间距、动效。  
- 所有列表、表单、详情页保持相同交互范式，降低学习成本。

## 二、全局布局结构

采用经典 **左导航 + 右内容** 布局，顶部状态栏固定。

```
┌─────────────────────────────────────────────────────────────┐
│  顶部状态栏（系统状态 + 用户菜单）                           │
├───────────┬─────────────────────────────────────────────────┤
│           │                                                 │
│  侧边导航  │  主内容区                                       │
│           │  - 页面标题 + 面包屑                            │
│           │  - 快捷操作栏（可选）                           │
│           │  - 内容区域（卡片/表格/表单/图表）              │
│           │                                                 │
└───────────┴─────────────────────────────────────────────────┘
```

### 2.1 顶部状态栏（全局固定）
| 区域         | 内容                                      | 交互                           |
|--------------|-------------------------------------------|--------------------------------|
| 左侧         | Logo + 产品名称「WP极速面板」            | 点击跳转仪表盘                 |
| 右侧（从左至右） | 服务器时间（动态）                      | -                              |
|              | CPU/内存/磁盘使用率（环形小图标）        | 悬停显示详情，点击跳转监控页   |
|              | 一键优化悬浮球（常驻）                  | 点击展开快捷操作：清理缓存/数据库优化/全站加速 |
|              | 管理员头像/用户名下拉                  | 修改密码、退出登录、面板设置   |

### 2.2 侧边导航（可折叠）
导航按**用户任务**组织，而非按技术组件划分：

| 一级菜单       | 二级菜单（示例）            | 说明                                   |
|----------------|----------------------------|----------------------------------------|
| 📊 控制台      | -                          | 全局状态、网站数量、速度评分、预警     |
| 🌐 网站管理    | 网站列表 / 创建网站        | 核心操作区                             |
| 🚀 加速中心    | 缓存管理 / 图片优化 / 前端优化 / CDN | 将底层 LSCache/Redis/OPcache 等统一为“加速”概念 |
| 🛠️ 环境服务    | OpenLiteSpeed / PHP / 数据库 / Redis | 仅面向高阶用户，默认折叠；提供“自动优化”开关 |
| 🔐 安全与备份  | 安全防护 / 备份迁移        | -                                     |
| ⚙️ 系统设置    | 面板配置 / 日志 / 计划任务 | -                                     |

**设计要点**：
- 默认选中“控制台”，高频操作入口（如“创建网站”）在控制台提供快捷卡片。
- “环境服务”菜单默认收起，并在首次使用时提示“已为您自动优化，无需手动配置”。

## 三、页面详细设计（核心模块）

### 3.1 控制台 Dashboard —— 全局态势感知

**布局**：上下两栏，上为指标卡片，下为监控图表。

#### 上栏：指标卡片（3～4个）
1. **站点总数** + 今日新增（数值）  
2. **平均速度评分**（PageSpeed 移动端/桌面端）  
   - 环形进度条，颜色绿/黄/红  
   - 点击跳转“前端优化”页  
3. **缓存命中率**（整体）  
   - 环形进度条，点击跳转“缓存管理”  
4. **待处理任务**（如备份失败、SSL即将过期）  
   - 显示数字，点击展开详情列表  

#### 下栏：监控图表（左右两列）
- **左**：实时负载曲线（CPU/内存/网络）—— ECharts 面积图，时间范围 1h/6h/24h  
- **右**：请求与缓存命中曲线（QPS、LSCache命中、Redis命中）  

#### 右下角：**一键极速优化** 大按钮（悬浮效果）  
- 点击执行预设的全站优化流程，伴随进度提示与结果报告。

**融合策略**：  
- 用户无需进入任何子模块，即可看到“网站速度是否健康”。  
- 直接通过“一键极速优化”获得性能提升，无需理解 LSCache/Redis/OPcache。

---

### 3.2 网站管理 —— 创建站点即极致优化

#### 网站列表页
| 列           | 内容                                     | 操作                         |
|--------------|------------------------------------------|------------------------------|
| 域名         | 主域名 + 别名                           | 点击进入详情                 |
| PHP版本      | 8.2 / 8.1                               | -                            |
| 状态         | 运行中/停止/故障                        | -                            |
| 速度评分     | 90分（移动端）                          | 鼠标悬停显示详细分数         |
| 缓存状态     | 已开启（四层）                          | 标签，绿色                   |
| 操作         | 管理、清理缓存、SSL配置、备份           | 常用操作直接展示             |

**交互优化**：  
- 支持批量清理缓存、批量开启/关闭站点。

#### 创建站点 —— 极速引导模式
采用**分步表单（三步）**，每一步都隐藏技术细节：

**Step 1：基本信息**  
- 域名（自动检测是否已解析）  
- 站点名称（默认“My WordPress Site”）  
- 管理员邮箱（用于 SSL 证书）  

**Step 2：性能预设（关键融合）**  
- 提供三个滑块式选项：  
  - 🐢 兼容模式（低配置服务器，节省资源）  
  - ⚡ 均衡模式（默认推荐）  
  - 🚀 极速模式（激进缓存，适合高流量）  
- 下方**极简说明**：  
  > 极速模式：开启全站静态化、WebP 图片转换、Redis 对象缓存、CSS/JS 合并压缩。  
- **不展示任何技术名词开关**，用预设替代。

**Step 3：确认创建**  
- 展示配置摘要（PHP 8.2、MariaDB 10.6、Redis 已启用、SSL 自动）  
- 点击“立即创建”后进入进度动画（建站 + 自动优化）

**融合策略**：  
- 底层自动执行：创建虚拟主机、生成 LSCache 规则、安装 Redis Object Cache、设置 OPcache 参数、修改 wp-config.php。  
- 用户**无感知**却得到了完整性能栈。

#### 网站详情页
顶部标签页：
- **概览**：站点速度评分、缓存命中率、今日流量（PV/UV 需插件支持）、SSL 有效期。  
- **域名与 SSL**：绑定域名、申请证书、强制 HTTPS。  
- **缓存设置**：可视化调整缓存模式（同创建时三级滑块），**一键刷新缓存**。  
- **高级**（默认折叠）：php.ini 编辑、OLS 虚拟主机配置预览、数据库管理（跳转 PHPMyAdmin）。

---

### 3.3 加速中心 —— 将“技术组件”打包为“业务功能”

菜单包含：
- 缓存管理  
- 图片优化  
- 前端优化  
- CDN  

#### 3.3.1 缓存管理
**目标**：让用户像“开关灯”一样控制全站缓存，无需区分 LSCache/Redis/OPcache。

**界面设计**：
- 顶部**总开关**：开启/关闭全站缓存。  
- 下方**缓存模式**：三级滑块（同创建时），切换时显示预估效果变化。  
- 实时指标卡片：  
  - 整体缓存命中率（98%）  
  - Redis 内存使用量  
  - 页面缓存大小（磁盘）  
- **一键清理**按钮（全站、仅页面缓存、仅对象缓存）—— 通过下拉菜单区分，但仍用通俗语言。  

**融合策略**：  
- 用户只看见“缓存”，底层联动 LSCache 规则、Redis flush、OPcache reset。  
- 开启“极速模式”时自动配置 LSCache 高级参数（ESI、最大年龄等），完全隐藏。

#### 3.3.2 图片优化
**设计**：
- 显示所有站点的图片总容量、已优化比例、节省空间。  
- **批量优化**：选择站点 → 执行压缩 + WebP 转换 → 显示进度。  
- 设置：自动优化开关（新上传图片自动转 WebP）、压缩强度（无损/有损）、保留原图。  

**融合策略**：  
- 本地执行，不依赖 API，后台自动调用 cwebp、avifenc。  
- 自动替换 WordPress 上传路径及前端输出代码（懒加载、picture 标签）。

#### 3.3.3 前端优化
**设计**：
- **PageSpeed 检测**：输入 URL → 获取分数 → 列出优化建议。  
- **一键修复**按钮，自动执行：  
  - 合并/压缩 CSS/JS  
  - 生成 Critical CSS  
  - 字体本地化  
  - 移除 WP 头部无用标签  

**融合策略**：  
- 将复杂的前端优化步骤封装为单个任务，耗时较长时通过 WebSocket 推送实时日志。  
- 支持回滚操作（保留备份）。

### 3.4 环境服务 —— 专业模式（默认隐藏）

仅当用户点击“展开高级设置”时显示。  
每个服务（OLS/ PHP/ 数据库/ Redis）采用**统一卡片布局**：

| 区域         | 内容                                            |
|--------------|-------------------------------------------------|
| 服务状态     | 运行中 / 停止（带启动/停止按钮）                |
| 版本信息     | 显示当前版本，如有新版本提示                    |
| 配置优化     | “推荐配置”按钮（应用预设的最佳参数）            |
| 监控简表     | 关键指标（如 PHP 请求数、数据库连接数、Redis 命中率） |
| 更多         | 跳转到详细配置页（可视化编辑/日志查看）         |

**融合策略**：  
- 默认全部服务已应用“极速模板”，用户**几乎不需要**进入此页。  
- 提供“恢复默认优化”按钮，防止误操作。

## 四、交互与视觉规范

### 4.1 色彩系统
- 主色：Arco Blue (`#165DFF`) —— 代表速度、信任。  
- 功能色：  
  - 成功：绿色 (`#00B42A`)  
  - 警告：橙色 (`#FF7D00`)  
  - 危险：红色 (`#F53F3F`)  
- 中性色：大量留白，浅灰分割线。  

### 4.2 字体与间距
- 字体：Inter（无衬线），14px 常规，16px 标题。  
- 卡片内边距：20px。  
- 圆角：8px 基础圆角，按钮 6px。  

### 4.3 响应式
- 侧边栏支持折叠，主内容区自适应。  
- 监控图表在小屏幕下堆叠显示。  

### 4.4 反馈机制
- **操作反馈**：按钮点击即刻展示“加载中”状态，成功/失败使用 Arco Message 轻提示。  
- **长时间任务**（如优化、备份）：进度条 + 后台通知（右上角）。  
- **错误处理**：统一错误弹窗，展示可读性提示，附带“查看日志”链接。

## 五、性能优化功能“无感融入”具体策略清单

| 底层技术                     | 前端呈现方式                                      | 用户感知                         |
|------------------------------|---------------------------------------------------|----------------------------------|
| OpenLiteSpeed 虚拟主机配置   | 网站创建时自动生成，无需配置                      | 无感                             |
| LSCache 页面缓存规则         | 缓存管理 → 三级滑块（标准/激进/静态化）          | “我选了快速模式”                |
| Redis Object Cache           | 缓存管理 → 总开关开启即自动配置                  | “缓存已开启”                    |
| OPcache 参数优化             | 默认已应用“极速模板”，环境服务页提供“恢复优化”按钮 | 几乎无感                         |
| MariaDB 查询缓存 / 碎片清理  | 数据库管理 → 一键优化按钮                        | “数据库优化”                    |
| 图片压缩与 WebP 转换         | 图片优化 → 批量优化 / 自动优化开关               | “图片变轻了”                    |
| CSS/JS 合并压缩、Critical CSS| 前端优化 → 一键修复 PageSpeed 问题               | “速度评分提高了”                |
| CDN 静态资源替换             | CDN 接入 → 输入 CDN 域名，自动替换               | “资源走 CDN 了”                 |
| 系统级 TCP/内核参数          | 面板安装时自动设置，无需干预                      | 无感                             |
| 定时备份、清理               | 系统设置 → 计划任务（可选）                     | “自动备份了”                    |

**关键设计原则**：  
1. **默认最优**：安装即优化，用户不需要任何配置。  
2. **场景化聚合**：将多个技术点打包成一个业务操作。  
3. **可视化的价值**：通过速度评分、缓存命中率让用户感知优化效果。  
4. **渐进式披露**：复杂配置默认隐藏，通过“高级”、“更多设置”按需展开。

## 八、总结

本方案完全遵循“简洁轻量、无感性能融合”的核心诉求：

- **将 20+ 底层性能优化技术点** 封装为 **5 个业务功能模块**（缓存、图片、前端、CDN、一键优化）。  
- **默认最优配置** + **一键优化** 覆盖 90% 用户需求，高级用户可通过“环境服务”微调。  
- 布局采用标准左右结构，信息密度适中，所有操作 3 步内完成。  

此策划可直接用于前端开发排期，页面数量约 15 个，核心交互集中在 P0 页面，可快速 MVP 验证。

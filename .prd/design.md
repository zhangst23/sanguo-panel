# Sanguo Panel 视觉设计规范

> **文档版本**：1.0  
> **设计系统**：基于 Arco Design Vue 主题定制  
> **适用场景**：面板前端 UI 设计、组件开发、主题统一  
> **目标读者**：AI 设计师、前端开发者、产品经理

---

## 1. 设计理念

- **极简克制**：信息密度适中，减少视觉噪音，让用户聚焦核心操作。
- **速度感**：通过清爽的蓝白主色调、灵活动效、实时数据刷新，传递“快”的感受。
- **信任感**：使用克制的阴影、清晰的字体层级、圆润但不幼稚的圆角，营造专业可靠的氛围。
- **一致性**：所有页面遵循相同的色彩、间距、组件交互模式，降低学习成本。

## 3. 字体与排版

### 3.1 字体家族
```css
--font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', 
               'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 
               'Helvetica Neue', Arial, sans-serif;
```
- 数字和英文字体优先使用 **Inter**，获得更好的可读性与现代感。
- 中文字体回退为系统默认无衬线字体。

### 3.2 字号与行高
| 层级     | 字号 | 行高 | 字重   | 应用场景                     |
| -------- | ---- | ---- | ------ | ---------------------------- |
| H1       | 28px | 42px | SemiBold | 页面大标题（极少使用）       |
| H2       | 20px | 30px | Medium   | 卡片标题、模块标题           |
| H3       | 16px | 24px | Medium   | 二级标题、列表项标题         |
| 正文     | 14px | 22px | Regular  | 绝大多数文本、表格内容       |
| 辅助文本 | 12px | 20px | Regular  | 提示信息、标签、时间戳       |
| 小字号   | 10px | 16px | Regular  | 角标、极次要信息             |

### 3.3 字重
- Regular: 400
- Medium: 500  
- SemiBold: 600

### 3.4 行高规则
- 标题行高一般取 1.5 倍
- 正文行高取 1.57 倍（22/14）

## 4. 布局与网格

### 4.1 页面结构
- **全局布局**：左侧导航固定（折叠态宽 60px，展开态 220px），右侧内容区自适应。
- **内容区**：内边距统一 `20px`。
- **卡片间距**：垂直间距 `16px`，水平间距 `20px`。

### 4.2 响应式断点
| 断点        | 尺寸范围    | 行为                           |
| ----------- | ----------- | ------------------------------ |
| `xs` (手机) | < 576px     | 侧边栏自动折叠，卡片纵向堆叠   |
| `sm` (平板) | 576px ~ 768px | 侧边栏可手动折叠，图表自适应   |
| `md` (桌面) | 768px ~ 992px | 正常显示，保持两列卡片布局     |
| `lg` (宽屏) | > 992px     | 三列卡片，图表区域更宽         |

### 4.3 栅格系统
基于 Arco 的 24 栅格，主要用于表单和复杂卡片布局：
```vue
<a-row :gutter="20">
  <a-col :span="16">主要内容</a-col>
  <a-col :span="8">侧边信息</a-col>
</a-row>
```

## 5. 组件样式规范

### 5.1 按钮（Button）
| 类型     | 样式                                       | 应用场景                     |
| -------- | ------------------------------------------ | ---------------------------- |
| 主按钮   | 背景 `#165DFF`，白色文字，圆角 `6px`       | 关键操作（创建、保存、优化） |
| 次按钮   | 白底，边框 `#C9CDD4`，文字 `#4E5969`       | 次要操作（取消、关闭）       |
| 文字按钮 | 无边框，文字 `#165DFF`                    | 表格内操作、更多链接         |
| 危险按钮 | 背景 `#F53F3F`，白色文字                  | 删除、重置、高危操作         |

**尺寸**：
- 大：高度 `36px`，内边距 `0 16px`
- 中：高度 `32px`，内边距 `0 12px`
- 小：高度 `28px`，内边距 `0 8px`

### 5.2 卡片（Card）
- 背景色 `#FFFFFF`，圆角 `8px`，内边距 `20px`
- 阴影：`0 2px 8px 0 rgba(0, 0, 0, 0.04)`
- 边框：无，依赖阴影区分层次

### 5.3 表格（Table）
- 无边框模式，行高 `52px`
- 表头背景 `#F7F8FA`，字重 Medium
- 斑马纹：偶数行浅灰背景 `#FAFAFA`
- 悬停行：背景 `#E8F3FF`
- 操作列：文字按钮，居右

### 5.4 表单（Form）
- 标签对齐：右对齐，宽度 `100px`
- 输入框高度 `32px`，边框 `#E5E6EB`，圆角 `6px`
- 聚焦边框：`#165DFF`，阴影 `0 0 0 2px rgba(22,93,255,0.1)`
- 错误状态：边框 `#F53F3F`，提示文字红色

### 5.5 导航菜单（Menu）
- 侧边导航：展开时文字左对齐，图标 `16px`，间距 `12px`
- 选中态：背景 `#E8F3FF`，文字 `#165DFF`，左侧蓝色竖条 `3px`
- 悬停态：背景 `#F7F8FA`

### 5.6 标签（Tag）
- 圆角 `4px`，内边距 `0 8px`，高度 `24px`
- 运行中：绿色背景 `#E8FFE8`，绿色文字 `#00B42A`
- 停止：灰色背景 `#F7F8FA`，灰色文字 `#86909C`
- 故障：红色背景 `#FFECE8`，红色文字 `#F53F3F`

### 5.7 进度条（Progress）
- 线性进度条，高度 `8px`，圆角 `4px`
- 已完成部分：品牌蓝 `#165DFF`
- 背景色：`#F2F3F5`

### 5.8 滑块（Slider）
- 三级缓存模式滑块：三个圆点标记，下方显示模式标签
- 轨道高度 `4px`，圆角 `2px`
- 已选中部分：品牌蓝 `#165DFF`

### 5.9 空状态（Empty）
- 插图 + 标题 + 操作按钮
- 插图风格：线性轮廓，主色 `#C9CDD4`
- 标题：16px Medium，辅助文字：14px Regular

## 6. 图标与插图

### 6.1 图标库
- 优先使用 **Arco Icon** 内置图标，确保风格统一。
- 自定义业务图标（如 CDN、缓存、一键优化）使用 `@arco-design/color` 线性风格，尺寸 `16px` / `20px`。
- 侧边导航图标统一 `16px`，展开态右侧无文字时居中。

### 6.2 插图风格
- 面板内无复杂插画，仅保留空状态、404、500 等场景。
- 采用 **两色线性风格**：主轮廓深灰色 `#4E5969`，辅色品牌蓝 `#165DFF` 25% 透明度。

## 7. 动效与交互反馈

### 7.1 过渡动画
- **页面切换**：`fade` 渐隐渐现，时长 0.2s
- **侧边栏折叠**：宽度变化配合 `ease` 曲线，时长 0.2s
- **模态框**：从屏幕中心淡入并轻微放大，时长 0.2s

### 7.2 即时反馈
- **按钮点击**：轻微缩放（0.98） + 透明度变化
- **操作成功**：顶部全局提示 `Message.success('操作成功')`，绿色主题
- **操作失败**：红色主题，显示错误详情（可收起）
- **长时间任务**：进度条 + 后台任务通知中心

### 7.3 加载状态
- **局部加载**：Spinner 旋转动画，尺寸 `24px`，品牌蓝
- **页面加载**：骨架屏（Skeleton），模仿卡片布局

---

## 8. 响应式与移动适配

- **管理面板不优先支持移动端**，但需保证关键信息在平板（768px~992px）下可读。
- 窄屏下：
  - 侧边栏自动折叠为图标栏
  - 多列卡片变为单列
  - 表格启用横向滚动
  - 图表高度自适应

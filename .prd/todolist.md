# Sanguo Panel 开发任务清单 (Todolist)

本清单根据产品需求文档 (PRD) 和技术架构要求制定，按优先级 (P0/P1/P2) 和功能维度划分。

## P0 核心骨架与 MVP 功能 (第一迭代目标)

### 系统与环境初始化
- [x] 后端项目骨架初始化 (FastAPI, 目录结构, 基础依赖, JWT 认证)
- [x] 前端项目骨架初始化 (Vue3, Vite, Arco Design, Pinia, 路由)
- [x] 基础数据库设计实现 (SQLite 面板库初始化, `users`, `sites`, `shared_databases` 等表)

### 后端核心业务 (FastAPI)
- [x] 认证系统: 登录、Token 验证、管理员管理
- [x] 系统状态接口: CPU、内存、磁盘负载采集 (WebSocket + REST)
- [x] 网站管理 (Shared DB 模式):
    - [x] 站点创建逻辑: 自动生成 OLS 虚拟主机配置, 生成唯一表前缀, 初始化 wp-config.php
    - [x] 站点列表与基础信息
    - [x] 站点删除 (保留/删除数据库选项)
- [x] 缓存控制中心: 四层缓存总开关逻辑 (LSCache/Redis/OPcache/Browser)
- [x] 共享数据库管理: 实例注册、连接测试、表前缀冲突检测

### 前端核心界面 (Vue3 + Arco Design)
- [x] 登录页实现
- [x] 全局布局 (左导航 + 顶部状态栏)
- [x] 控制台 (Dashboard): 实时负载卡片, 性能指标概览
- [x] 网站列表与分步创建引导 (性能预设滑块)
- [x] 缓存管理中心 (三级滑块模式切换)

## P1 性能增强与运维工具 (第二迭代目标)

### 性能优化
- [x] 图片优化模块: 批量压缩、WebP/AVIF 自动转换、懒加载配置
- [x] 前端资源优化: CSS/JS 合并压缩、Critical CSS 生成、字体本地化
- [x] 数据库高级管理: 慢查询分析、一键优化/修复、碎片整理

### 运维与安全
- [x] 备份与恢复: 站点级全站备份 (限定表前缀), 自动/手动任务
- [x] SSL 自动管理: 集成 Certbot/acme.sh 申请与续期
- [x] 安全加固: 隐藏登录路径, 禁用 XML-RPC, 防火墙端口管理

## P2 扩展功能与高级监控 (持续优化)

- [x] CDN 一键接入: Cloudflare 等主流厂商 API 对接, 静态资源替换
- [x] 详细监控中心: 历史性能曲线图, 数据库查询耗时分布
- [x] 一键全站极速优化按钮: 自动化执行所有预设优化流程
- [x] 多 PHP 版本切换与 PHP 扩展管理可视化
- [x] 一键部署: WordPress, Typecho 等

---
## 规范说明
1. 每个功能开发前需更新此 Todolist。
2. 开发完成后撰写 `test-case.md`。
3. 测试通过后记录至 `notelist.md`。
4. 编码遵循 DRY/KISS/SOLID/YAGNI 原则。

# Sanguo Panel 开发记录 (Notelist)

## 2026-02-12: 项目启动与骨架搭建

### 已完成功能
1.  **后端基础架构**:
    - 基于 FastAPI 的模块化结构。
    - Pydantic Settings 环境配置。
    - SQLAlchemy + SQLite 数据库初始化，支持自动建表。
    - JWT 认证系统（OAuth2 兼容）。
    - 系统监控接口（psutil 获取硬件状态）。
2.  **前端基础架构**:
    - Vue3 + Vite + Arco Design 组合。
    - 响应式布局设计（BaseLayout）。
    - 动态路由配置与权限控制（路由守卫）。
    - Axios 请求拦截器封装（处理 Token 和错误提示）。
    - Dashboard 实时监控图表基础实现。
3.  **站点管理 (P0)**:
    - 后端实现了 Site 和 SharedDatabase 的模型与 API。
    - 前端实现了站点列表展示、创建站点弹窗、删除确认。
    - 初始化时自动创建默认管理员和默认共享数据库。
4.  **LiteSpeed 管理 (P1)**:
    - 后端实现了服务状态查询和重启的通用接口。
    - 在 Windows 环境下对服务操作进行了 Mock 处理。
    - 前端实现了 LiteSpeed 管理面板，支持查看状态和重启操作。
5.  **PHP 管理 (P1)**:
    - 延用了通用的服务管理接口。
    - 前端实现了多版本 PHP (8.2, 8.1, 7.4) 的管理界面。
6.  **MariaDB 管理 (P1)**:
    - 实现了共享数据库实例的管理功能。
    - 前端支持查看 MariaDB 服务状态、重启服务以及管理共享库配置。
7.  **Redis & 缓存管理 (P1)**:
    - 前端集成了 Redis 服务监控与操作。
    - 支持一键清空 Redis 键值和清理 LiteSpeed 全局对象缓存。
8.  **安全管理 (P1)**:
    - 实现了管理员密码修改功能。
    - 提供了面板安全配置界面，支持 Token 有效期管理、2FA 开关及 IP 白名单设置。
9.  **系统管理 (P1)**:
    - 实现了基础配置管理（面板名称、语言、时区）。
    - 集成了日志查看器，支持查看不同类型的系统日志。
    - 实现了版本检查与更新接口。
10. **监控统计 (P2)**:
    - 集成 ECharts 实现了 CPU、内存的实时趋势图。
    - 实现了 24 小时网络流量统计图表。
11. **一键部署 (P2)**:
    - 实现了应用商店界面，支持 WordPress、Typecho、Nextcloud 的模拟安装流程。
12. **备份管理 (P2)**:
    - 实现了备份记录查看与下载功能。
    - 提供了定时备份计划配置（频率、保留份数、存储位置）。
13. **缓存控制中心 (P0)**:
    - 后端实现了基于站点的缓存配置 API 和预设应用逻辑。
    - 前端实现了三级滑块（Basic/Balanced/Ultimate）快速切换性能预设。
    - 支持细粒度控制 LSCache、Redis、OPcache 和浏览器缓存。
14. **SSL 自动管理 (P1)**:
    - 后端实现了 SSL 证书申请 (Mock Certbot)、状态检查和禁用功能。
    - 前端提供了直观的 SSL 列表，支持一键申请 Let's Encrypt 证书并配置强制 HTTPS。
15. **图片优化模块 (P1)**:
    - 后端实现了图片统计查询和模拟批量优化任务 API。
    - 前端提供了统计图表、质量调节滑块和 WebP/AVIF 转换开关。
    - 实现了实时日志展示功能，模拟扫描和优化过程。
16. **数据库高级管理 (P1)**:
    - 后端实现了慢查询记录模拟、表状态查询和一键优化 API.
    - 前端集成了慢查询展示、表空间占用详情以及一键清理/优化流程。
    - 支持显示碎片占用 (Overhead) 并通过优化回收空间。
17. **前端资源优化 (P1)**:
    - 后端实现了资源状态查询和模拟优化逻辑（合并压缩、Critical CSS）。
    - 前端提供了直观的资源健康度检查列表。
    - 支持一键执行 CSS/JS Minify 和 Google 字体本地化。
18. **CDN 一键接入 (P2)**:
    - 后端实现了 CDN 厂商连接模拟和全局刷新 API。
    - 前端集成了主流 CDN (Cloudflare) 的快速接入流程。
    - 支持连接状态检查、CNAME 展示及手动缓存刷新。
19. **一键全站极速优化 (P2)**:
    - 后端实现了聚合优化 API，串联执行缓存、图片、资源、数据库和 CDN 的优化任务。
    - 前端设计了“一键全速”英雄界面，提供沉浸式的任务执行反馈。
    - 提供了优化预估得分提升的反馈。

### 技术要点
- **数据库**: 使用 `as_declarative` 统一基类，自动生成表名。
- **认证**: 使用 `passlib` (bcrypt) 处理密码，`jose` 处理 JWT。
- **前端布局**: 使用 Arco Design 的 `a-layout` 组合，支持侧边栏折叠。
- **实时性**: Dashboard 采用 `setInterval` 定期拉取监控数据。

## 2026-02-13: 后端启动修复与站点创建功能完善

### 已完成功能
1.  **后端启动环境优化**:
    - 修复了 `PYTHONPATH` 导致的 `ModuleNotFoundError` 问题。
    - 统一了数据库文件路径为 `backend/panel.db`，避免在根目录产生多余文件。
    - 优化了 `uvicorn` 启动参数，增加了 `--reload-exclude "*.db"`，解决了数据库写入触发服务无限重启导致的“一直转圈圈”问题。
2.  **数据库架构一致性**:
    - 修复了 `sites` 表缺少性能优化相关字段（如 `performance_preset`, `lscache_enabled` 等）的问题。
    - 重新初始化了数据库，确保所有 P0/P1 功能所需的字段均已正确创建。
    - 实现完整数据库模型（Task, Backup, Firewall, Options），支持后续真实功能开发。
3.  **任务系统基础**:
    - 建立后台异步任务系统基础（Task 追踪与进度上报），并集成到“一键全站极速优化”功能中。
4.  **前端站点管理优化**:
    - 优化了 `WebsiteList.vue` 的创建流程，增加了表单校验和提交时的 `loading` 状态。
    - 修复了 `shared_db_id` 在初始加载时可能为 `null` 导致提交失败的问题。

### 技术要点
- **Uvicorn 配置**: 在开发模式下使用 `--reload` 时，必须排除数据库文件，否则 SQLite 写入操作会导致服务重启。
- **FastAPI 启动钩子**: 在 `main.py` 中增加了 `startup` 事件日志，方便确认服务是否正常启动。

### 注意事项
- 后端启动命令已更新，建议使用 `README.md` 中提供的最新启动方式。
- 如果之前已创建数据库，建议删除 `panel.db` 并运行 `python backend/init_db.py` 重新初始化以应用最新的 Schema。

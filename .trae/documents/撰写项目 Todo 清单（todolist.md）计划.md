# 目标
- 基于 PRD/技术/设计/SQL 文档，在 doc-ai/prd/todolist.md 输出面向实施的任务清单，按 P0/P1/P2 优先级与前后端/系统/数据维度分组，用动词开头、结果明确的条目（勾选式）。

# 文件结构与书写规范
- 顶部说明：任务编写原则（DRY/KISS/SOLID/YAGNI）、条目格式与验收口径。
- 分组层次：
  - P0（MVP 必须）：前端、后端、系统/实时、数据/共享库、测试与质量、设计主题落地。
  - P1（增强与优化）：图片优化、前端优化、环境服务概览、数据库管理细化、监控中心。
  - P2（扩展）：CDN 接入、安全与备份扩展、系统设置完善、报告导出等。
- 条目风格：中文、动词短句、可验证产出（页面/接口/脚本/配置），避免纯讨论性任务。

# P0 任务大纲（将写入 todolist.md 的具体清单）
- 前端（Vue3 + Arco + Pinia + Axios + ECharts）：
  - 初始化前端项目骨架与主题变量（global.scss 按设计规范 2/5/9 章节）。
  - 路由与守卫、登录页（JWT 流程）、控制台（指标卡 + 监控图）、一键优化入口。
  - 网站列表/详情/创建（三步引导 + 性能预设滑块）、缓存管理页（总开关/三级滑块/命中率）。
  - WebSocket 客户端封装与实时数据订阅（系统状态、命中率）。
- 后端（FastAPI 模块化）：
  - 认证与安全：JWT、密码哈希、统一响应格式、结构化日志。
  - 系统信息/监控推送：REST + WebSocket（CPU/内存/磁盘/QPS）。
  - 网站管理：共享数据库模式站点生命周期（生成唯一表前缀、wp-config 写入、OLS 虚拟主机）。
  - MariaDB/Redis/LSCache/OPcache 的“缓存中心”编排接口（总开关、模式、清理/预热）。
  - 任务系统：后台任务记录、进度推送、取消/错误管理。
- 系统与实时：
  - Systemd/子进程控制 OLS/MariaDB/Redis，配置安全备份与回滚。
  - WebSocket 广播管理与节流；定时任务（APScheduler）初始化。
- 数据与共享库：
  - 面板管理库初始化（users/sites/tasks/shared_databases 等，按 sql.md）。
  - 共享数据库实例 CRUD 与告警阈值（表数量阈值）。
  - 站点级仅前缀表操作（备份/优化/清理时限定前缀）。
- 测试与质量：
  - API 与服务单元测试骨架、Swagger 校验；基础集成测试（创建站点到首页可访问）。
- 设计与体验：
  - 侧边导航与顶部状态栏按设计规范实现；反馈机制与加载状态统一（Message/Skeleton）。

# P1 任务大纲
- 图片优化：批量压缩、WebP/AVIF 转换、懒加载、恢复原图。
- 前端优化：CSS/JS 合并压缩、HTML 压缩、Critical CSS 生成、字体本地化与预加载、移除无用资源。
- 环境服务概览：OLS/PHP/MariaDB/Redis 卡片页（推荐配置、一键恢复）。
- 数据库管理：慢查询日志、碎片整理、一键优化。
- 监控中心：全屏图表与历史数据存储、TTFB 与 PageSpeed 检测。

# P2 任务大纲
- CDN 接入：Cloudflare 一键配置、静态资源替换、缓存刷新、强制 CDN 模式。
- 安全与备份：防火墙规则、后台路径隐藏、防暴力破解、失败封禁、文件权限修复、XML-RPC 关闭、版本隐藏。
- 系统设置：端口修改、日志查看、JWT 密钥管理。
- 报告与一键工具：生成测速报告 PDF；一键环境修复/清理垃圾/数据库优化等卡片化工具完善。

# 验收标准（摘自 PRD）
- 纯净系统一键安装后运行；通过面板创建站点并访问首页，TTFB < 200ms。
- 开启一键优化后移动端 PageSpeed ≥ 90；WebSocket 数据准确，无页面报错。

# 安全/规范
- 所有接口需 JWT；敏感操作记录日志；默认仅开放必要端口；密码/密钥不入库明文。
- 遵循 DRY/KISS/SOLID/YAGNI，超 500 行模块拆分。
